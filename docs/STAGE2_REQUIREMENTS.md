# Stage 2 – Project Requirements & Development Plan

## Functional Requirements

1. Display Linux system information.
2. Display CPU model, core count, usage and load.
3. Display RAM and swap information.
4. Display root filesystem usage.
5. Enumerate running processes.
6. Search processes by name.
7. Send SIGTERM to a selected PID.
8. Save a health snapshot to a log file.
9. Calculate a simple overall health state.
10. Provide a Linux character-device driver component.

## Non-Functional Requirements

- Linux-only execution.
- C++17 for the application.
- Modular source structure.
- Clear error handling.
- Low runtime overhead.
- Git-based version control.
- Clear README and documentation.

## Modules

- System Information
- CPU Monitor
- Memory Monitor
- Disk Monitor
- Process Monitor
- Health Monitor
- Logger
- Kernel Driver
