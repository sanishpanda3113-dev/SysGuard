# Stage 1 – Project Introduction

## Project Title
SysGuard – Linux System Health Monitor

## Problem Statement
Linux provides system information through many different utilities and virtual filesystems. Users often need to use several commands to understand CPU, memory, storage and process activity. SysGuard combines these monitoring tasks into one lightweight C++ command-line application.

## Objective
The objective is to develop a Linux-only system monitoring tool using C++ that demonstrates system programming, operating-system concepts, computer architecture and user-space/kernel-space interaction.

## Scope
The project covers:
- System and kernel information
- CPU monitoring
- Memory monitoring
- Disk monitoring
- Process enumeration and basic process control
- Health assessment
- Logging
- A small optional Linux character-device driver

## Expected Outcome
A working CLI tool that provides a consolidated view of system health and demonstrates how a C++ program interacts with Linux system interfaces and the kernel.

## Applications
- Basic system diagnostics
- Learning Linux system programming
- Resource monitoring
- Demonstrating OS and hardware/software concepts
